## ファイル・添付資料

### ブラウザで直接閲覧
レポートファイルをダウンロードせずにブラウザ上で表示できます。

**使い方**
1. コースページから提出済みレポートを開く
2. ファイル名をクリック
3. ファイルが新しいタブで表示される

**対応ファイル形式**
- PDF、Word、Excel、PowerPointなど

### 新しいタブで開く
ファイルを自動的に新しいタブで表示します。ポップアップウィンドウは表示されません。

### 教材の操作パネル
教科書ページの目次の上に、選択中の節を操作するパネルが表示されます。

**ボタン**
- **保存**: ファイルを直接ダウンロード
- **保存先**: 保存先と名前を選んで保存
- **表示**: 新しいタブでプレビュー表示（PDFのみ）

目次の行にある添付ファイルには、同じ3つの操作がアイコンボタンで表示されます。

ストリーミング配信の動画では、保存／保存先ボタンで動画をMP4に変換して保存します（変換はブラウザ内で行います）。進行状況と結果はパネル内に表示されます。

保存前に変換結果を自動で検証し、壊れたファイルは保存しません。検証で問題が見つかった場合は、どの動画で何が起きたかをエラーとして表示します。

- 映像・音声の欠落（一部だけ無音になる、映像が途切れるなど）
- 映像と音声の長さの不一致
- 未対応の形式（MP3音声、HEVC映像、暗号化、音声が別配信の動画など）
- ログイン切れなどで動画以外のデータを受け取った場合

### 全動画の結合保存
節ごとに動画が分かれている教材で、操作パネルに「全N本を結合して保存」ボタンを追加します。全節の動画を順番につなげて、1つのMP4として保存します。

- 拡張機能の設定「全動画の結合保存ボタンを表示」をオンにすると表示（デフォルトはオフ）
- 動画が2本以上ある教材でのみ表示
- 節ごとに解像度や音声の形式が異なる場合は結合できません（エンコード設定の違いだけなら結合できます）

### 教材動画の連続再生
節ごとに動画が分かれている教材で、動画が終わると次の節へ進み、続けて再生します。

- 拡張機能の設定「教材の動画を連続再生」で切り替え
- 1つの節に複数の動画がある場合は、その節の動画を順に再生してから次の節へ進む
- 最後の節の動画が終わると停止
- ブラウザの自動再生制限にかかった場合はミュートで再生し、動画の下に案内を表示

### ポップアップ防止
添付資料リンクをクリックしても、ポップアップウィンドウは開かず、新しいタブで開きます。

## メッセージ機能

### タブでメッセージを開く
メッセージツールをポップアップウィンドウではなく、通常のタブで開きます。

**メリット**
- ブラウザの「戻る」ボタンが使える
- タブとして管理できる
- ポップアップブロッカーの影響を受けない

### 一括既読機能
表示中のページのメッセージをワンクリックで既読にできます。

**使い方**
1. メッセージ（受信箱）を開く
2. 「ダウンロード」の右にある「すべて既読にする」ボタンをクリック
3. 表示中のページのメッセージ（最大30件）が既読になる

※ 受信箱が複数ページある場合は、ページごとに操作してください

## 締切・課題管理

### 締切警告の強調表示
e-class が科目一覧に出す「締切が近い課題があります。」を、時計マーク付きの赤い札として目立たせます。

**判定基準**
- e-class 自身の判定（公開中で締切まで7日以内の課題がある科目）に従います
- 設定でオフにすると e-class 本来の表示に戻ります

### 締切課題リスト
科目一覧ページのサイドバーに、締切が近い課題を一覧表示します。

**表示内容**
- 科目名（クリックすると科目ページへ移動）
- 未提出の課題名
- 締切までの残り時間（1分ごとに更新）と締切日時

**表示のルール**
- e-class が「締切が近い課題があります。」と表示している科目が対象
- 公開中で締切まで7日以内の未提出の課題を、締切が近い順に表示
- 残り24時間を切った課題は残り時間を赤字で表示
- 提出済みの課題は表示しない
- 課題の詳細を取得できなかった科目は、科目名だけを表示

### 科目のピン留め
よく使う科目をピン留めして素早くアクセスできます。

**使い方**
1. 科目リンクにマウスを合わせる
2. 科目名の横にピンのアイコンが表示される（ピン留め済みの科目は常に表示）
3. クリックしてピン留め
4. サイドバーの「ピン留め科目」に表示される

**ピン解除**
- 「ピン留め科目」の行にマウスを合わせ、× ボタンをクリック
- または科目名の横のピンのアイコンをもう一度クリック

**特徴**
- ブラウザを閉じても保持される
- 複数の科目をピン留め可能

## コースナビゲーション

### 目次
コースページの左の列（タイムラインの下）に表示される目次です。

**機能**
- **教材タイプアイコン表示**: 資料、試験、レポートなどを区別
- **未読教材の表示**: 未読教材に青いドット
- **新規教材の表示**: 新しい教材がある回と教材に「New」を表示
- **利用できない教材の表示**: 教材がすべて利用できない回と、利用できない教材に鍵アイコンを表示
- **スクロール連動ハイライト**: 現在表示中のセクションを自動強調
- **自動展開・折りたたみ**: スクロール位置に応じて該当セクションのみ展開

**使い方**
- サイドバーの項目をクリックすると、該当セクションにスクロール
- 設定でオン・オフ切り替え可能

**表示位置**
- 左の列のタイムラインの下に表示
- スクロールしても左の列ごと画面内に表示（画面より長い場合は列の中でスクロール）

### タイムラインの開閉
コースページの「タイムライン」の見出しを押すと、タイムラインを閉じたり開いたりできます。閉じた状態は記憶され、次に開いたコースページでも閉じたまま表示されます。

## 時間割カスタマイズ

### 土曜日を非表示
時間割表の土曜日列を非表示にします。

**使い方**
- 拡張機能アイコンをクリック
- 「土曜日を非表示」をオン
- リアルタイムで反映

### 6・7限を非表示
6限と7限の行を非表示にします。

**使い方**
- 拡張機能アイコンをクリック
- 「6・7限を非表示」をオン
- リアルタイムで反映

### セクション折りたたみ
科目一覧ページで、以下のセクションを折りたたみ・展開できます。

**対象セクション**
- 管理者からのお知らせ
- 時間割表
- その他の科目リスト
- 学期フィルター

**使い方**
- 各セクションの見出しをクリック
- 折りたたみ・展開が切り替わる
- 状態は自動保存される

**メリット**
- 画面のスクロールを減らせる
- 必要な情報に素早くアクセスできる

## クイズ機能

### クイズコピーボタン
個別のクイズ問題と解答をクリップボードにコピーできます。

**使い方**
1. クイズページを開く
2. 各問題の横に「コピー」ボタンが表示される
3. ボタンをクリック
4. 問題文、選択肢、解答がコピーされる

**コピー形式**
```
問題1: 問題文
A. 選択肢1
B. 選択肢2
C. 選択肢3
正解: A
```

### クイズ一括エクスポート
すべてのクイズ内容を一括でエクスポートできます。

**使い方**
1. クイズページを開く
2. ページ上部に2つのボタンが表示される
   - 「クリップボードにコピー」
   - 「ファイルに保存」
3. どちらかをクリック

**クリップボードにコピー**
- すべてのクイズ内容がクリップボードにコピーされる
- Wordやメモ帳に貼り付け可能

**ファイルに保存**
- テキストファイルとしてダウンロード
- ファイル名: `quiz_export_YYYYMMDD_HHMMSS.txt`

**用途**
- 復習用メモの作成
- 問題のバックアップ
- 学習資料の作成

## その他の機能

### ダークモード
e-classページをダークテーマで表示します。

**使い方**
- 拡張機能アイコンをクリック
- 「ダークモード」をオン
- リアルタイムで反映

**特徴**
- 目に優しい配色
- 夜間の学習に最適
- すべてのe-classページに適用

### E-classトップボタン
コースページから科目一覧ページ（トップページ）に素早く戻れます。

**使い方**
- コースページの「トップへ戻る」ボタンの隣に表示される
- 「E-class Top」ボタンをクリック
- 科目一覧ページに移動

### フッターブランディング
すべてのe-classページの下部にBetterE-classのバージョン情報が表示されます。

**表示内容**
- 「🚀 BetterE-class v1.8.1」
- クリックするとGitHubリポジトリが開く

**用途**
- バージョン確認
- 拡張機能が正しく動作しているかの確認

## 設定

拡張機能アイコンをクリックすると、設定パネルが開きます。

### 設定項目一覧

| 設定項目 | 説明 | デフォルト |
|---------|------|----------|
| **ダークモード** | ダークテーマを適用 | オフ |
| **土曜日を非表示** | 時間割表の土曜日列を非表示 | オフ |
| **6・7限を非表示** | 6限と7限の行を非表示 | オフ |
| **目次** | コースページの左の列に目次を表示 | オン |
| **教材の動画を連続再生** | 動画が終わったら次の節へ進んで再生 | オフ |
| **全動画の結合保存ボタンを表示** | 教材の全動画を1つのMP4に結合して保存 | オフ |

### 設定の保存
- 設定は自動的に保存される
- ブラウザを閉じても保持される
- リアルタイムで反映される

### 設定のリセット
設定をデフォルトに戻したい場合は、各項目を手動で変更してください。

## トラブルシューティング

### 拡張機能が動作しない
1. Chromeを最新版に更新
2. 拡張機能を再読み込み
3. ページをリロード

### ボタンが表示されない
1. ページを再読み込み
2. 設定を確認（オフになっていないか）
3. コンソールでエラーを確認

### 設定が保存されない
1. ブラウザのストレージ権限を確認
2. 拡張機能を再インストール
