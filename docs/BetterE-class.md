## ファイル・添付資料

### ブラウザで直接閲覧
レポートファイルをダウンロードせずにブラウザ上で表示できます。

**使い方**
1. コースページから提出済みレポートを開く
2. ファイル名をクリック
3. ファイルが新しいタブで表示される

**対応ファイル形式**
- PDF、Word、Excel、PowerPointなど

### 新しいタブで開く
ファイルを自動的に新しいタブで表示します。ポップアップウィンドウは表示されません。

### 教材の操作パネル
教科書ページの目次の上に、選択中の節を操作するパネルが表示されます。

**ボタン**
- **保存**: ファイルを直接ダウンロード
- **保存先**: 保存先と名前を選んで保存
- **表示**: 新しいタブでプレビュー表示（PDFのみ）

目次の行にある添付ファイルには、同じ3つの操作がアイコンボタンで表示されます。

ストリーミング配信の動画では、保存／保存先ボタンで動画をMP4に変換して保存します（変換はブラウザ内で行います）。進行状況と結果はパネル内に表示されます。

保存前に変換結果を自動で検証し、壊れたファイルは保存しません。検証で問題が見つかった場合は、どの動画で何が起きたかをエラーとして表示します。

- 映像・音声の欠落（一部だけ無音になる、映像が途切れるなど）
- 映像と音声の長さの不一致
- 未対応の形式（MP3音声、HEVC映像、暗号化、音声が別配信の動画など）
- ログイン切れなどで動画以外のデータを受け取った場合

### 全動画の結合保存
節ごとに動画が分かれている教材で、操作パネルに「全N本を結合して保存」ボタンを追加します。全節の動画を順番につなげて、1つのMP4として保存します。

- 拡張機能の設定「全動画の結合保存ボタンを表示」をオンにすると表示（デフォルトはオフ）
- 動画が2本以上ある教材でのみ表示
- 節ごとに解像度や音声の形式が異なる場合は結合できません（エンコード設定の違いだけなら結合できます）
  - 結合できないときは、どの節の画面の大きさや音声がどう違うかを表示します（例: 第1節「講義の概要」は1920×1080・48kHz・ステレオ、第2節「統計学と確率論」は1920×1200・32kHz・モノラル）。その場合は保存ボタンで1本ずつ保存してください

### 教材動画の連続再生
節ごとに動画が分かれている教材で、動画が終わると次の節へ進み、続けて再生します。

- 拡張機能の設定「教材の動画を連続再生」で切り替え
- 1つの節に複数の動画がある場合は、その節の動画を順に再生してから次の節へ進む
- 最後の節の動画が終わると停止
- ブラウザの自動再生制限にかかった場合はミュートで再生し、動画の下に案内を表示

### 教材動画のミュート状態の引き継ぎ
教材の動画でミュートにすると、次の動画や次の節の動画もミュートのまま始まります。ミュートを解除すると、次の動画からは音ありで始まります。

- 設定は不要で、常に有効
- 連続再生でも、目次から節を選んだ場合でも引き継ぐ
- 引き継ぐのは同じ教材を開いている間だけ。教材を開き直すと元に戻る

### 教材動画のミュート再生
教材の動画を常にミュート（消音）の状態で始めます。電車の中などで字幕を見ながら視聴するときに便利です。

- 拡張機能の設定「教材の動画をミュートで再生」で切り替え（デフォルトはオフ）
- 連続再生で次の動画や次の節へ進んでも、ミュートのまま再生
- 連続再生がオフでも、自分で再生した動画に適用
- プレーヤーでミュートを解除した動画はそのまま。次の動画はまたミュートで始まる（この設定がオンの間は、ミュート状態の引き継ぎより優先）

### ポップアップ防止
添付資料リンクをクリックしても、ポップアップウィンドウは開かず、新しいタブで開きます。

## メッセージ機能

### タブでメッセージを開く
メッセージツールをポップアップウィンドウではなく、通常のタブで開きます。

**メリット**
- ブラウザの「戻る」ボタンが使える
- タブとして管理できる
- ポップアップブロッカーの影響を受けない

### 一括既読機能
表示中のページのメッセージをワンクリックで既読にできます。

**使い方**
1. メッセージ（受信箱）を開く
2. 「ダウンロード」の右にある「すべて既読にする」ボタンをクリック
3. 表示中のページのメッセージ（最大30件）が既読になる

※ 受信箱が複数ページある場合は、ページごとに操作してください

## 締切・課題管理

### 締切警告の強調表示
e-class が科目一覧に出す「締切が近い課題があります。」を、時計マーク付きの赤い札として目立たせます。

**判定基準**
- e-class 自身の判定（公開中で締切まで7日以内の課題がある科目）に従います
- 設定でオフにすると e-class 本来の表示に戻ります

### 締切課題リスト
科目一覧ページのサイドバーに、締切が近い課題を一覧表示します。

**表示内容**
- 科目名（クリックすると科目ページへ移動）
- 未提出の課題名
- 締切までの残り時間（1分ごとに更新）と締切日時

**表示のルール**
- e-class が「締切が近い課題があります。」と表示している科目が対象
- 公開中で締切まで7日以内の未提出の課題を、締切が近い順に表示
- 残り24時間を切った課題は残り時間を赤字で表示
- 提出済みの課題は表示しない
- 課題の詳細を取得できなかった科目は、科目名だけを表示

### 科目のピン留め
よく使う科目をピン留めして素早くアクセスできます。

**使い方**
1. 科目リンクにマウスを合わせる
2. 科目名の横にピンのアイコンが表示される（ピン留め済みの科目は常に表示）
3. クリックしてピン留め
4. サイドバーの「ピン留め科目」に表示される

**ピン解除**
- 「ピン留め科目」の行にマウスを合わせ、× ボタンをクリック
- または科目名の横のピンのアイコンをもう一度クリック

**特徴**
- ブラウザを閉じても保持される
- 複数の科目をピン留め可能

## コースナビゲーション

### 目次
コースページの左の列（タイムラインの下）に表示される目次です。

**機能**
- **教材タイプアイコン表示**: 資料、試験、レポートなどを区別
- **未読教材の表示**: 未読教材に青いドット
- **新規教材の表示**: 新しい教材がある回と教材に「New」を表示
- **利用できない教材の表示**: 教材がすべて利用できない回と、利用できない教材に鍵アイコンを表示
- **スクロール連動ハイライト**: 現在表示中のセクションを自動強調
- **自動展開・折りたたみ**: 読んでいる回とその前後の回（合わせて3回分）を開いておき、スクロールに合わせて入れ替える（自分で開閉した回はそのまま）

**使い方**
- サイドバーの項目をクリックすると、該当セクションにスクロール
- 設定でオン・オフ切り替え可能

**表示位置**
- 左の列のタイムラインの下に表示
- スクロールしても左の列ごと画面内に表示（画面より長い場合は列の中でスクロール）

### タイムラインの開閉
コースページの「タイムライン」の見出しを押すと、タイムラインを閉じたり開いたりできます。閉じた状態は記憶され、次に開いたコースページでも閉じたまま表示されます。

## 時間割カスタマイズ

### 土曜日を非表示
時間割表の土曜日列を非表示にします。

**使い方**
- 拡張機能アイコンをクリック
- 「土曜日を非表示」をオン
- リアルタイムで反映

### 6・7限を非表示
6限と7限の行を非表示にします。

**使い方**
- 拡張機能アイコンをクリック
- 「6・7限を非表示」をオン
- リアルタイムで反映

### セクション折りたたみ
科目一覧ページで、以下のセクションを折りたたみ・展開できます。

**対象セクション**
- 管理者からのお知らせ
- 時間割表
- その他の科目リスト
- 学期フィルター

**使い方**
- 各セクションの見出しをクリック
- 折りたたみ・展開が切り替わる
- 状態は自動保存される

**メリット**
- 画面のスクロールを減らせる
- 必要な情報に素早くアクセスできる

## クイズ機能

### 問題をコピー
表示中の問題の問題文と選択肢をクリップボードにコピーできます。

**使い方**
1. クイズ・課題のページを開く
2. 問題文の上の「問題をコピー」ボタンをクリック
3. コピーできるとボタンにチェックの印が出る（失敗したときはボタンの横に理由を表示）

**コピー形式**
```
問題文（画面と同じ行で改行）
1 選択肢1
2 選択肢2
```

### 全てコピー・全て出力
すべての問題を順番に表示して集め、まとめてコピーまたはテキストファイルに保存できます。

**使い方**
1. クイズ・課題のページを開く
2. 左の列の「全てコピー」または「全て出力」をクリック
3. ボタンが「もう一度押して開始」に変わり、集める問題の数が表示される
4. もう一度クリックすると開始（6秒以内に押さなければ取り消し）
5. 集めている間は進み具合（例: 問題を集めています 2/5）を表示
6. 終わると最初の問題に戻り、「5問をコピーしました」のように結果を表示

**全てコピー**
- すべての問題がクリップボードにコピーされる
- タブが裏にあってコピーできなかったときは、ボタンが「コピーする」に変わる。もう一度押すとコピーされる

**全て出力**
- テキストファイルとしてダウンロード
- ファイル名は教材名（例: `第2回 小テスト.txt`）

**出力形式**
```
Q1. 問題文
1 選択肢1
2 選択肢2

Q2. 問題文
…
```

**用途**
- 復習用メモの作成
- 問題のバックアップ
- 学習資料の作成

## その他の機能

### ダークモード
e-classページをダークテーマで表示します。

**使い方**
- 拡張機能アイコンをクリック
- 「ダークモード」をオン
- リアルタイムで反映

**特徴**
- 目に優しい配色
- 夜間の学習に最適
- すべてのe-classページに適用

### E-classトップボタン
コースページから科目一覧ページ（トップページ）に素早く戻れます。

**使い方**
- コースページの「トップへ戻る」ボタンの隣に表示される
- 「E-class Top」ボタンをクリック
- 科目一覧ページに移動

### フッターブランディング
すべてのe-classページの下部にBetterE-classのバージョン情報が表示されます。

**表示内容**
- 「Powered by WebClass | BetterE-class v1.8.3」
- 「BetterE-class v1.8.3」をクリックするとGitHubリポジトリが開く

**用途**
- バージョン確認
- 拡張機能が正しく動作しているかの確認

## 設定

拡張機能アイコンをクリックすると、設定パネルが開きます。

### 設定パネルの使い方
- 左の列でカテゴリを選ぶと、右にそのカテゴリの設定が表示される
- カテゴリ名の横の数字は「オンの項目数/項目数」
- 「設定を検索」に言葉を入力すると、すべてのカテゴリから一致する設定を表示（Escキーで解除）
- 最後に開いたカテゴリは、次に開いたときも表示される
- キーボードでは、カテゴリを上下の矢印キーで切り替えられる
- パネルの配色は、パソコンのライト／ダーク設定に合わせて切り替わる

### 設定項目一覧

| カテゴリ | 設定項目 | 説明 | デフォルト |
|---------|---------|------|----------|
| 動画 | **教材の動画を連続再生** | 動画が終わったら次の節へ進んで再生 | オフ |
| 動画 | **教材の動画をミュートで再生** | 教材の動画を常にミュートの状態で始める | オフ |
| 動画 | **全動画の結合保存ボタンを表示** | 教材の全動画を1つのMP4に結合して保存 | オフ |
| ファイル・リンク | **ダウンロードボタンを表示** | 教材や添付ファイルに保存ボタンを追加 | オン |
| ファイル・リンク | **レポートを新しいタブで開く** | レポート一覧のファイルを新しいタブで表示 | オン |
| ファイル・リンク | **添付ファイルを新しいタブで開く** | 添付ファイルの別ウインドウ表示を新しいタブに置き換え | オン |
| ファイル・リンク | **メッセージのポップアップを抑止** | メッセージ画面を通常のタブで開く | オン |
| トップページ | **締切の強調表示** | 締切が近い課題を強調し、一覧表示 | オン |
| トップページ | **土曜日を非表示** | 時間割表の土曜日列を非表示 | オフ |
| トップページ | **6・7限を非表示** | 6限と7限の行を非表示 | オフ |
| コース | **目次を表示** | コースページの左の列に目次を表示 | オン |
| 外観 | **ダークモード** | ダークテーマを適用 | オフ |
| 開発者向け | **デバッグモード** | コンソールに詳細なデバッグ情報を表示 | オフ |

### 設定の保存
- 設定は切り替えた時点で自動的に保存される（保存に失敗したときだけ、スイッチが元に戻ってメッセージが表示される）
- ブラウザを閉じても保持される
- ほとんどの設定はすぐに反映される。「↻」の注記がある設定は、切り替えると開いている e-class のページを再読み込みして反映する

### 設定のリセット
設定をデフォルトに戻したい場合は、各項目を手動で変更してください。

## トラブルシューティング

### 拡張機能が動作しない
1. Chromeを最新版に更新
2. 拡張機能を再読み込み
3. ページをリロード

### ボタンが表示されない
1. ページを再読み込み
2. 設定を確認（オフになっていないか）
3. コンソールでエラーを確認

### 設定が保存されない
1. ブラウザのストレージ権限を確認
2. 拡張機能を再インストール
